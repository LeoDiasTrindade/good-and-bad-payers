\section*{Declaration of AI use}
Two language models were used in this project. Sol generated the LaTeX
template of this article. Claude Opus 5.5 (Anthropic) was used to review the
exploratory notebook, to write the modelling code following the author's
decisions, and to draft the text of this article and of the slides. The
author chose the dataset, the question and the methods, and checked and
edited all code and text.

METHOD

Two models, one protocol

Logistic regression

p = σ(β₀ + xᵀβ), fitted on the log-loss. Each e^β is an odds ratio, so a refusal can be explained.

log(1 + x) on long tails, standardized, ridge or lasso.

Main method · Lectures 9 and 11

Random forest

300 trees on bootstrap samples, √p features per split. Finds non-linear effects and interactions by itself.

Tuned: minimum number of clients per leaf.

Comparison · Lecture of 13/11

1 · Split

80/20, stratified. The test set stays locked.

2 · Choose

5-fold stratified CV for every choice.

3 · No leakage

Everything that learns sits inside the pipeline.

4 · Grade

Pick by log-loss, report AUC, open the test once.

I chose two models from opposite ends of a trade-off that Lecture 9 described for credit. The logistic regression is the main method: it gives a probability, and every coefficient is an odds ratio, so the bank can explain a refusal. The random forest is the comparison: it finds non-linear effects and interactions on its own, but is harder to explain. Both go through the same protocol: a stratified 80-20 split with the test locked away, five-fold cross-validation for every choice, every step that learns inside the pipeline so nothing leaks, and the test opened only once.

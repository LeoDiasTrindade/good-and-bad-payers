LogReg and RF models

Logistic regression

  • p = σ(β₀ + xᵀβ), fitted on the log-loss
  • Each e^β is an odds ratio, so a refusal can be explained
  • log(1 + x) on long tails, standardized, ridge or lasso

Random forest

  • 300 trees on bootstrap samples, √p features per split
  • Finds non-linear effects and interactions by itself
  • Tuned: minimum number of clients per leaf

The same protocol for both

  • Split: 80/20, stratified; the test set stays locked until the end.
  • Choose: 5-fold stratified cross-validation for every choice.
  • No leakage: everything that learns sits inside the pipeline.
  • Grade: pick by log-loss, report AUC, open the test set once.

I compared two models from opposite ends of the trade-off discussed in Lecture 9. The logistic regression is the main method: every coefficient is an odds ratio, so a refusal can be explained to the client. The random forest finds non-linear effects and interactions on its own, but is harder to explain. Both follow the same protocol: a stratified 80/20 split with the test set locked away, five-fold cross-validation for every choice, and the test set opened only once, at the end.
